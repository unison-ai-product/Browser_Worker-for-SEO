# 完成時チェックと修正の運用

## 1. 記事完成時のチェック項目

### 全体チェック

- [ ] タイトルはクリックしたくなる魅力的な内容か
- [ ] タイトルに SEO キーワードが含まれているか（機械: 施策キーワードの有無）
- [ ] リード文は読み進めたい内容になっているか
- [ ] リード文に記事の概要が含まれているか
- [ ] 目次の階層構造に間違いはないか（機械: H2 飛ばしの H3 の検出）
- [ ] 目次を読んで全体の話の流れがつかめるか
- [ ] 各見出しは魅力的な内容か
- [ ] 結論ファーストの文章構成になっているか

### 詳細チェック

- [ ] 画像や表は適切に配置されているか（機械: alt 欠落）
- [ ] 誤字脱字が発生していないか
- [ ] 冗長な表現になっていないか（機械: 辞書）
- [ ] 二重表現を用いていないか（機械: 辞書）
- [ ] 差別的な表現が使われていないか（機械: 辞書で一部）
- [ ] 固有名詞は適切に書かれているか（機械: 略語辞書）
- [ ] 引用ルールは守られているか（機械: blockquote の出典有無）
- [ ] 適切に装飾され見やすくなっているか
- [ ] ネガティブな表現がされていないか（機械: 辞書で一部）
- [ ] 内部リンクが適切に配置されているか（機械: 本数）

## 2. 修正 3 回の運用（本プラグインの決定 2026-09-16）

| 回 | 見るもの | マニュアルのタイミング | 本プラグイン（同一タスク内） |
|---|---|---|---|
| 1 回目（推敲） | 文章全体: 構成の崩れ、補足、過分な内容、表現の分かりやすさ | 完成直後 | fix-integrator の統合直後 |
| 2 回目（校正・校閲） | 文と単語: 誤字脱字、冗長、文法、事実の正誤、差別的表現 | 完成 2〜3 日後 | 1 回目に続けて keyword-gate + fact-checker |
| 3 回目（校了） | 修正の崩れ: 投稿時の崩れ、画像・表・装飾 | 投稿前 | WP 下書きのプレビュー確認時（procedures/seo-write.md 手順9） |
