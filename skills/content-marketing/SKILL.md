# コンテンツマーケティングスキル — 内部リンクと CV 導線

> 各節末尾に ****。**サイト固有の語（ファネル段階名・キーワード例・カテゴリ名・トピック名・サービス名・CTA 文言）はこのスキルに書かない。** `knowledge/config/site-profile.yaml`（/SEO設定 が作る。記入例は templates/site-profile.example.yaml）と `knowledge/links/priority-articles.csv` から読み、未定義なら「未定義」と扱う。

## 1. 内部リンクの役割（3 原則）

### 1-1. キーワードの分類で逆行するリンクの使用はしない

- トピック内のキーワードにはフェーズ（site-profile.yaml `funnels` の段階順）がある。
- リンクはフェーズを**進める方向**に張る。戻る方向には張らない。
- 各段階にどのキーワード語が属するかは `funnels[].keywords` の定義に従う。
- リード文下の内部リンクは、現在のキーワードより同一トピックにおける**抽象度の高い**キーワードの記事へ（`outline.lead_link` が true のとき）。

### 1-2. 単語数が増えるほど CV に近い

- キーワードは単語数が増えるほど悩みが顕在化し、CV に近い記事になりやすい。
- 内部リンクは**単語数が増える方向**に設置する（1 単語 ⇒ 2 単語 ⇒ 3 単語 ⇒ 4 単語以上）。
- ツリー型リンク構造: メインワード（少ない単語数）の記事を親とし、単語を足した子記事はすべて親へ集約する（「事前に読みたい」で親に戻すのは抽象度の方向であり、フェーズの逆行ではない）。

### 1-3. カテゴリーは CV しやすい方向へ

- カテゴリーは `categories.order` の順で右へ行くほど CV を取りやすいように設計されている。
- チャンスがあれば右のカテゴリーの記事に行くように仕向ける。
- 同一カテゴリー内でも右（CV 側）の記事に誘導するように内部リンクを貼る。
## 2. 記事の目的分類（4 分類）

| 目的 | 役割 | 内部リンクの向き |
|---|---|---|
| 集客・興味付け | 入口。読者が最初に触れる記事 | 教育・共感の記事へ |
| 教育・誘導 | 判断材料を与える記事 | 共感・CV の記事へ |
| 共感・納得 | 不安や疑問を言語化して寄り添う記事 | CV の記事へ |
| CV | 行動直前の読者に向けた記事 | CTA |

- 記事の目的は 1 つに決める（seo-outline §2「ブロックの目的」と区別: こちらは記事全体）。
- **CV している記事には優先的にリンクを設置**する。CV 実績のある記事の一覧は `knowledge/links/priority-articles.csv`（キーワード / タイトル / URL）。
## 3. CV 導線の作り方（H2 パターン 6 型）

構成案の H2 の並びを決める型。各行が 1 つの H2。「目的 → H2 の内容 → 着地点 → リンク」。
「サービス訴求」の行は `outline.service_h2` / `cta` が定義されているときだけ入れる。

### 3-1. ターゲット絞り込み型（特定の属性 × 行動）

| 目的 | 見出し内容（H2） | 着地点 | リンク |
|---|---|---|---|
| 結論 | ○○な方は○○である | 即断できる人はここで CV | CTA |
| 理由 | ○○な方は○○な理由 | 納得できた人はここで CV | CTA |
| 行動喚起 | だから○○な方は今すぐ行動 | 前半をまとめた CV | CTA |
| 解決策 | ○○で悩んでいる方は○○をしろ | 信頼を勝ち取るための情報提供 | さらなる情報提供の内部リンク |
| 提案 | ○○な方こそ○○を使って欲しい | サービス訴求 | CTA |

### 3-2. 問題指摘型（失敗 / できない / 衰退 など）

| 目的 | 見出し内容（H2） | 着地点 | リンク |
|---|---|---|---|
| 問題提起 | こんな場面に直面していないだろうか？ | 不安の顕在化 | CTA |
| 危険性 | このままではうまくいかないどころか損をする | 危機感 | CTA |
| 具体例 | 具体的にはこのようなことになる | 足りない部分を暗示 | 情報提供の内部リンク |
| 失敗点 | 多くの人がここで失敗する | 危険性の一般化 | CV する記事へ内部リンク |
| 解決策 | 解決策にはこういうものがある | 打開策 | CTA |
| 訴求 | 失敗しないためには○○を使って欲しい | サービス訴求 | CTA |

### 3-3. ベネフィット型（メリット / デメリット / おすすめ など）

| 目的 | 見出し内容（H2） | 着地点 | リンク |
|---|---|---|---|
| 推奨 | ○○をしたほうがいい | 結論を述べて訴求 | CTA |
| メリット | なぜならこんなメリットがあるから | 意向上げ | CTA |
| デメリット | しかし気を付けるべき点もある | 両面提示 | CV する記事へ内部リンク |
| 補足 | デメリットは小さくできる | 対策を提示 | CTA |
| 再推奨 | 総じて○○はおすすめである | 結論の再提示 | CTA |
| 訴求 | 詳しい内容は○○へ | サービス訴求 | CTA |

### 3-4. 共感型（否定的評判 / 大変 / 脱出 など）

| 目的 | 見出し内容（H2） | 着地点 | リンク |
|---|---|---|---|
| 問題 | ○○といわれるがその真偽は？ | 結論を述べて訴求 | CTA |
| 理由 | ○○といわれる理由 | 問題の暗喩 | さらなる情報提供の内部リンク |
| 共感 | ○○だとこうなってしまう | 共感 + 危機感 | CV する記事へ内部リンク |
| ポイント | ○○を解決しないといけない | 結論を述べて訴求 | CTA |
| 危険性 | ○○を放置するとこうなる | 従わない場合の危険性 | CV する記事へ内部リンク |
| 解決策 | 解決策は○○である | 従うと得られるメリット | CTA |
| 訴求 | 後悔しないためには | サービス訴求 | CTA |

### 3-5. 感情移入型（辞めたい / 危険 / 脱出 など）

| 目的 | 見出し内容（H2） | 着地点 | リンク |
|---|---|---|---|
| 主張 | ○○は○○である | 結論を述べて訴求 | CTA |
| 厳しさ | ○○といわれる理由 | 問題の暗喩 | さらなる情報提供の内部リンク |
| 体験談 | 自分（友人）もこうだった | 共感 + 危機感 | CV する記事へ内部リンク |
| 危険性 | ○○を解決しないといけない | 結論を述べて訴求 | CTA |
| 訴求 | 今すぐ行動に起こすこと | サービス訴求 | CTA |

### 3-6. 損失回避型（否定的評判 / 失敗 / 危険 / 劣悪環境 など）

| 目的 | 見出し内容（H2） | 着地点 | リンク |
|---|---|---|---|
| 理由 | ○○といわれる理由 | 理由を明記 | CV する記事へ内部リンク |
| 危険性 | ○○しないといけない | 危険性の示唆 | CTA |
| 比較 | A と B で大きな差がつく | 比較軸 | CTA |
| 損失 | ○○すると大失敗する | 損失の可能性 | CTA |
| 解決策 | ○○しないためには | 解決策 | CTA |
| 訴求 | 今すぐ利用しよう | サービス訴求 | CTA |
## 4. CTA・CTA ボタンの使用場面

- H2 の終わりには **CTA** を使用する。
- H3 内部で使用する場合は **CTA ボタン（またはバナー）** を使用する。
- H2・H3 がセットのとき、H2 のリード文下にテキスト CV リンクを挿入する（文言は `cta.text_link`）。
- CTA の種別名・文言・リンク先は `cta` から。未定義なら CTA を書かない。

```
H2：タイトル ⇒ CTA
H2：タイトル
　H3：タイトル ⇒ CTA ボタンまたはバナー
　H3：タイトル ⇒ CTA ボタンまたはバナー
　H3：タイトル ⇒ CTA
H2：タイトル ⇒ CTA
```
## 5. トピッククラスターの考え方

- メイントピックス = 別単語だが広い意味で同一系統の単語のまとまり。中分類・小分類で整理する（`topics`）。
- サブトピックの記事はすべて「事前に読みたい」でメイントピックの記事に内部リンクを集約する。
- トピックの型には「作業工程系」「スキル系」「将来性・需要系」「金銭系（単語数が増えるツリー型）」「働き方系」「職種・種類系（カテゴリー構造）」「ネガティブ系（未経験向け / 経験者向け）」「ポジティブ系」がある。サイトでどの型をどの語で持つかは `topics` に定義する。
## 6. 構成案調整のチェック（procedures/seo-outline.md 手順7 の出口）

- [ ] 記事の目的（§2）が 1 つに決まり、内部リンクの向きがその目的に合っている
- [ ] H3 の内部リンク先がフェーズを逆行していない（§1-1）
- [ ] 単語数が増える方向へのリンクがある（§1-2）
- [ ] CV している記事（priority-articles.csv）へのリンクを優先している
- [ ] H2 の並びが §3 のいずれかの型に沿っている（型名を構成案に書く）
- [ ] CTA の置き方が §4 に沿っている（CTA 先が未定義なら書かない）
