# 図解作成スキル

## 1. 図を入れる見出しの決め方（仕様メモ ④-2「見出しテーマに合わせて」）

構成案の各 H2 のテーマを次の型に当て、当たった H2 に図解候補を付ける。候補は構成案に `[図: 型]` として書き、ユーザー承認時に外せる（自動で全部作らない。承認された分だけ並列生成）。

| H2 のテーマ | 図の型 | 経路の既定 |
|---|---|---|
| 手順・流れ・時系列 | 流れ図（箱 + 矢印、3〜6 ステップ） | A（HTML/CSS） |
| 比較・違い・選び方 | 比較表（2〜3 列 × 3〜5 行） | A |
| 全体像・構成要素・関係 | 構造図（中心 + 周辺 / ツリー、要素 7 以下） | A |
| 数値・割合・推移 | グラフ（棒 / 折れ線 / 積み上げ。出典必須） | A |
| 概念・雰囲気・シーンの説明 | イラスト・イメージ図 | B（画像生成 AI） |

## 2. 経路 A — HTML/CSS → スクリーンショット PNG

1. `templates/figure.html`（1 枚 1 ファイル。幅 800px 固定・システムフォント・配色トークン）を雛形に、図を HTML/CSS で組む。要素の文言は本文と同じ用語、40 字以内 × 7 要素以下。
2. Claude in Chrome で `file://` またはローカルプレビューで開き、`computer` の screenshot / zoom で図の領域だけを撮る（読み取り操作。ゲート対象外）。
3. PNG を `memory/work/<kw>/figures/<h2-slug>.png` に保存。表示解像度に依存するため、必要なら幅 1600px の雛形で 2 倍にして撮る。
4. 同名 `.md` に alt / caption / 出典 / 挿入位置を書く。

## 3. 経路 B — 画像生成 AI をブラウザ操作（browser-worker imagegen の型）

- **前提**: どのサービス（Gemini / Canva / ChatGPT）のアカウントを持つかは `knowledge/config/config.yaml` の `imagegen` に記録済みであること（無ければ /SEO設定 で聞く。決め打ちしない）。ログインは人間。
- **節度**: 生成枠はユーザーのもの。**枚数の当てを先に合意**（「H2 3 本 × 各 1 枚」など）。Web UI の自動操作は量産に向かないので、量が増えたら正規 API への切替を提案。CAPTCHA・bot 検知は突破せず中断。
- **手順**（変更操作 = seo-start のゲート下）:
  1. プロンプト設計: 用途（記事内図解）・形状（横長 16:9 / 4:3）・テイスト・**文字は入れない**（生成 AI は文字が苦手。ラベルは後入れか本文で補う）。プロンプトをユーザーに提示して承認。
  2. `knowledge/sites/<service>.md` のランドマーク（入力欄・生成ボタン・画像の出現位置・ダウンロード導線）を確認。初回はフェーズ①でマッピング。
  3. 入力 → 生成待ち → 結果をスクショで提示 → リテイクは合意枚数の範囲内。
  4. 採用分だけフル解像度で取り込み（保存ボタン → ダウンロードフォルダ → `memory/work/<kw>/figures/`）。スクショ切り出しは本番素材に使わない（解像度が足りない）。
- 同名 `.md` に alt / caption / 「生成 AI 作成（サービス名）」/ 挿入位置。

## 4. 付随情報（同名 .md。fix-integrator が読む）

```
alt: <図の内容を 80 字で。中身を書く>
caption: <見出し 20 字> — <補足 40 字>
source: <出典。数値の図は必須。模式図は「模式図（当社作成）」。生成 AI は「生成AI作成（サービス名）」>
position: <挿入する H2/H3 名>
route: A | B
```

## 5. 禁止

- 出典の無い数値を描く（模式図なら「例」と明記）。
- 他社の図の模写、ロゴ・スクリーンショットの取り込み、人物の実写風生成。
- 図で本文と違う用語を使う。
- 経路 B で合意枚数を超えて生成する。

## 6. 決まり（ユーザー決定 2026-09-16）と未確定

- **経路 B のサービスと枚数上限は既定を持たない。** `/SEO設定` で `config.yaml` の `imagegen.service`（gemini / canva / chatgpt）と `imagegen.max_per_article` をユーザーが選ぶ。未設定なら経路 B を提案せず、経路 A だけで作る。
- 未確定: 経路 A の PNG の幅（WP 側の推奨幅）と、PNG を WP メディアにアップする方法（REST `media` = `wp-draft.py --media` か管理画面か）。/SEO設定 wp で決める。
