# SEO分析スキル — 調べる項目

> 各節の末尾に ****。「設計フォーマット」= 初心者向け設計フォーマット.xlsx の同名シート。「仕様」= SEO記事のコンテンツ制作用_Claude Coworkプラグイン.md。
> **サイト固有の値は書かない。** 想定検索者・ファネル段階・カテゴリ・サービス名は `knowledge/config/site-profile.yaml`（/SEO設定 が作る。雛形 templates/site-profile.example.yaml）から読む。未定義なら「未定義」と記録し、推測で区分を作らない。

## 0. 用語（記録に使う言葉はこれに揃える）

| 用語 | 定義 |
|---|---|
| 施策キーワード | 上位表示を狙うキーワード |
| 類似キーワード | 施策キーワード＋単語（キーワードマップ上） |
| 類似トピックス | キーワードマップ上のトピック |
| サジェストキーワード | 検索窓で表示される類似するキーワード |
| 関連する質問 | 検索結果中に出てくる Q&A |
| 他の人はこちらも検索 | 検索結果一番下に出てくるキーワード |
## 1. 検索結果上の情報収集項目（①SERPs解析で取る）

### 1-1. キーワード周辺

| 項目 | 取り方 |
|---|---|
| 施策キーワード | 引数 |
| 類似キーワード | キーワードマップ（シート `キーワードマップ`）から |
| 類似トピックス | キーワードマップから |
| サジェストキーワード | 検索窓に施策キーワードを入れた時の候補（Enter 前に read_page） |
| 関連する質問 | SERP の Q&A ブロック（質問文・展開後の回答要約・出典 URL） |
| 他の人はこちらも検索 | SERP 最下部のキーワード群 |
### 1-2. キーワード到達難度（6 段階。「上は多数、下は少数」）

| 段階 | 例（一般例。サイトを問わない） |
|---|---|
| 誰でも思いつく | 車 |
| 知っていたら思いつく | スバル |
| 調べていくうちに思いつく | スバル インプレッサスポーツ |
| 詳しく調べていれば思いつく | インプレッサスポーツ バッテリー サイズ |
| 経験がなければ想像できない | インプレッサスポーツ 点火プラグ 交換 |
| かなり高度な経験がなければ思いつかない | インプレッサスポーツ ディファレンシャル ギアオイル |

判定は AI が仮置き（`判定: AI仮置き`）。承認の要否は呼び出したコマンドの手順書が決める。
### 1-3. 想定検索者（サイト固有 — site-profile.yaml `personas` を読む）

- 区分名と「区分詳細」は site-profile.yaml に定義されたものだけを使う。
- 未定義なら `想定検索者: 未定義（/SEO設定 で定義）` と記録する。
- 雛形と記入例: templates/site-profile.example.yaml。
### 1-4. ファネル上の分類（サイト固有 — site-profile.yaml `funnels` を読む）

- ファネルは読者層ごとに複数持てる。各ファネルは「段階名 → 区分詳細 → 属するキーワード語」の順序付きリスト。
- 記事のキーワードがどの段階かを AI が仮置きする。
- 未定義なら `ファネル: 未定義` と記録する。雛形は templates/site-profile.example.yaml。
### 1-5. 検索意図

| 項目 | 内容 |
|---|---|
| 顕在化された検索意図 | 検索者が言葉にしている問い |
| 潜在的な検索意図 | 言葉にしていないが解決したいこと |
### 1-6. AIO（AI による概要）

| 項目 | 取り方 |
|---|---|
| AIO の有無 | ページ上部「AI による概要」ブロックの有無 |
| AIO 本文 | 「さらに表示」を展開した全文 |
| AIO 引用 URL | 引用リンクの URL とアンカー（順に） |
| 記事サイトの出現順位 | AIO と広告枠（「スポンサー」）を除いて数えた、記事型ページの順位 |
| 上位 5 記事のメタディスクリプション | SERP スニペット（可能なら `<meta name="description">` も） |
### 1-7. Yahoo!知恵袋

| 項目 | 取り方 |
|---|---|
| 知恵袋の出現 | SERP 内に知恵袋のページがあれば URL |
| 質問文とベストアンサー | 該当ページを開き、質問と BA を記録（記事順位には数えない） |
| H2 相当の論点 | 質問に含まれる SEO キーワードを抽出（§2 の表に 6 列目として並べる） |
## 2. 上位 5 記事の目次調査（②記事分析で取る）

> 目次をみて SEO 要素が含まれているか確認をする。他社競合の上位 5 サイトの目次をみて H2 タグに含まれる SEO 上の必須項目を抽出する。

各記事について:

| 項目 | 内容 |
|---|---|
| 順位 | 1〜5 位 |
| タイトル | |
| URL | |
| H2（目次） | H2 を上から順に |
| H2 に含まれる SEO キーワード | 各 H2 から抽出したキーワード |

5 記事 + Yahoo!知恵袋（§1-7）を並べ、**H2 に 3 本以上出るキーワードを「SEO 上の必須キーワード」、2 本を「推奨」**とする（ユーザー決定 2026-09-16）。
## 3. 記事を詳しく調査する項目（②記事分析で書く）

| 項目 | 内容 | 書き手 |
|---|---|---|
| キーワードに対する社会的な回答パターン | 上位記事と知恵袋が概ねどう答えているか | AI（事実の整理） |
| 世間的な回答への賛同 | 賛同する / しない | **AI見解**と明記 |
| その理由 | | AI見解 |
| ベストアンサー記事の URL | 個人的見解で OK | AI見解 |
| ベストアンサー記事の回答 | | AI（要約） |
| ベストアンサー記事の良かった点 | | AI見解 |
| 1 位である要因、または 1 位ではない要因の考察 | | AI見解 |
| この記事をどのように修正すれば勝てそうか？ | | AI見解 |

「AI見解」のセルは当社の立場ではない。当社の立場はユーザーオリジナルメモリ（knowledge/memory/original.md）から別に取り、混ぜない（ユーザー決定 2026-09-16）。
## 4. 仕様メモ由来の追加調査項目（②記事分析）

| 項目 | 内容 |
|---|---|
| 見出し配下の内部リンク | 各 H2 配下の同一ドメインリンク → 記事内の遷移マップ |
| 主義・主張の分類 | 世論強化 / 世論反対 / 中立。主張の切り抜き + 他社が書いていない差別化要素 |
| AIO 引用箇所 | AIO 引用 URL の記事で、AIO 本文の出所となる段落を特定して記録 |
| 構造化データ | WebFetch で取れる JSON-LD（@type 等）と、LLM が通常見るテキスト（本文プレーンテキスト） |
| 推移マップ | SERP 上の検索推移マップと記事推移マップを作成して照合 |
