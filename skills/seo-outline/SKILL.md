# SEO構成案スキル — 決める項目

> 各節末尾に ****。入力は seo-analysis の §1〜§4 が埋まっていること。
> **サイト固有の見出し・リンク慣習は書かない。** `knowledge/config/site-profile.yaml` の `outline:` 節（/SEO設定 で定義）を読み、未定義の項目は入れない。

## 1. 当社オリジナルブレンド（構成案の骨格を決める項目）

| 項目 | 内容 | 由来 |
|---|---|---|
| 施策キーワード | ※検索結果が同じもの（表記ゆれ・語順違いで SERP が同一のキーワード群をまとめる） | seo-analysis §0 |
| SEO 上の必須キーワード | ※H2 に必要（上位 5 記事から抽出。3 本以上で必須、2 本で推奨） | seo-analysis §2 |
| 導線設計上のキーワード | ※必須ではないが差別化として入れるもの | seo-analysis §4 差別化要素 + content-marketing |
| 内部リンク上のキーワード | ※H3 に入れる内部リンク上のキーワード | content-marketing |
| あなたの検索キーワードに対する回答 | 記事が出す答え（1〜2 文） | AI 案 + ユーザーオリジナルメモリ |
| あなたの検索キーワードに対する回答の根拠 | 回答を支える事実・一次情報 | 同上 |
| 記事タイトル | **32 字以内**（ユーザー決定 2026-09-16）。型・記号の慣習は media-rules.md に定義があればそれに従う | |
| 記事の骨組み（H2・H3） | §3 の書式。**H2 数・H3 数は上位 5 記事の中央値を目安**（ユーザー決定 2026-09-16） | |
| 記事の要約（300 文字程度） | | |
## 2. 記事の詳細設計（ブロックごと）

H2 を 1 ブロックとし、ブロックごとに次を書く（ブロック数は H2 数に合わせる）:

| 項目 | 内容 |
|---|---|
| ブロックの目的 | このブロックで読者に何を得させるか（content-marketing の「目的」語彙: 結論 / 理由 / 行動喚起 / 解決策 / 提案 等） |
| 文字数の目安 | |
## 3. 骨組みの書式（H2・H3 と内部リンクの並べ方）

```
カテゴリー：<site-profile.yaml categories から>
タグ：<キーワードのフェーズ語（site-profile.yaml funnels[].keywords から）>
単語数：<n 単語（施策キーワード）>
キーワードの区分：<ファネル段階（site-profile.yaml funnels から。未定義なら省略）>

タイトル | <記事タイトル> | 内部リンク先 | リンク先のフェーズ
[リード文下 | 事前に読みたい | <上位概念の記事>]   ← site-profile.yaml outline.lead_link が true のときだけ
見出し構成 | 1. <H2> | <CTA or 内部リンク先> | <フェーズ>
           | 　1-1. <H3> | <内部リンク先タイトル> | <フェーズ>
           | 　1-2. <H3> | <内部リンク先タイトル> | <フェーズ>
           | 2. <H2> | CTA |
           | …
           | N-1. よくある Q&A（H3 = 質問文）
           [| N. <サービス訴求 H2>]   ← site-profile.yaml outline.service_h2 に定義があるときだけ
```

- H2 番号は `1.` `2.`、H3 は `1-1.` `1-2.`（全角スペースでインデント）。
- 各 H3 に「内部リンク先（記事タイトル）」と「リンク先のフェーズ」。無ければ `記事未作成`（新規記事候補として構成案末尾に列挙）。
- CTA の置き方は content-marketing §4（H2 末尾は CTA、H3 内は CTA ボタンまたはバナー）。CTA 先は site-profile.yaml `cta` から。未定義なら `CTA: 未定義` と書く。
- **固定見出し（サービス訴求 H2・事前に読みたい）は site-profile.yaml の定義があるときだけ入れる**。プラグイン既定では入れない（ユーザー決定 2026-09-16: サイト専用ではなくカスタマイズで対応）。
## 4. 仕様メモ由来の項目（③の成果物に含める）

| 項目 | 内容 |
|---|---|
| AIO 引用方針 | AIO 原文から抽出した引用テーマを必須テーマ項目化し、どの H2/H3 で応えるか |
| 模擬クエリファンアウトの結果 | サブクエリと AIO 一致の対応表（llmo-analysis） |
| 見出し配下内部リンク | site:検索で自社記事からピックアップした H2/H3 ごとのリンク先（§3 の「内部リンク先」列） |
| コンテンツ方針 | 立場（世論強化 / 反対 / 中立）・オリジナル要素・一次情報の有無 |
| キーワードゲート結果 | 必須キーワードの網羅チェック（gate-script） |
| 敵対検証の要点 | 他社記事の見出し構成と比較した指摘と反映（adversarial-reviewer） |
## 5. 記録先

- スプレッドシート `構成案`（列 = §1 → §4 → §2 のブロック設計。§3 の骨組みはセル内改行で書式のまま）+ seo.db `outlines`
- 列定義の正本は templates/sheet-layout.md

## 6. 判定の決まり（ユーザー決定 2026-09-16）

| 論点 | 決定 |
|---|---|
| タイトル | 32 字以内。型は media-rules に定義があれば従う |
| H2・H3 数 | 上位 5 記事の中央値を目安 |
| サービス訴求 H2 / 事前に読みたい | プラグイン既定では入れない。site-profile.yaml の定義があるときだけ |
| CTA 先 | site-profile.yaml `cta` から。未定義なら書かない |
