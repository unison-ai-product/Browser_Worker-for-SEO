# 記事の組み立て方

## 1. 基本の型 — 階層構造

```
H1 タイトル
リード文
【目次】
本文: H2 見出し → H3 小見出し → H2 → H3 …
```
H1 ＞ H2 ＞ H3 ＞ H4 の階層化構造を厳守。

## 2. 記事戦略

- 記事のゴール: キーワードを通じて最終的にユーザーにどうなって欲しいか、どう感じて欲しいか、サイトが目指す方向と合致するか。
- 記事の方向性を言語化する（無いと「何が言いたいの？」になる）。
- 結論・主張を成立させる要素を取りまとめてストーリーを作り、SEO 上の網羅性を担保してどの順番で展開するかを決める（無いと「羅列されただけ」になる）。
- 記事のタイプを見極め、網羅性なのか感情優先なのかを判断する。

## 3. 記事構成の考え方

- 構成段階が勝負。記事構成は「結論・主張までのルートをどう辿るか」。
- SEO 要素（検索上位に共通する項目）は網羅性を担保する要因でしかない。結論を成り立たせるために SEO 要素を活用する。
- SEO 要素は必ずしも H2 である必要はなく、補足の小見出し（H3）で追加すればよい。
- 例（施策キーワード「Webライター 初心者」、主張「Web ライターはブログを作れ」）: SEO 要素「とは / メリット・デメリット / 始め方 / 稼ぎ方 / 注意事項 / スキル / よくある質問」を「仕事内容 → 得られるメリット → 収益形態 → 未経験の難しさ → 成功するスキルと特長 → よくある失敗談 → 実績はブログで作れ」の順に組み替える。

## 4. リード文

- 役割: サイトを開くかを決めるのがタイトル、記事を読むかを決めるのがリード文。
- 構成は記事の役割で書き分け、要素の組み合わせで作る:

| 位置 | 要素の候補 |
|---|---|
| 冒頭 | 問題提起 / 共感 / 説明 |
| 中盤 | 具体例 / 説明 / 理由 |
| 終盤 | 答え / ベネフィット / メリット |
| 文末 | 記事の概要（「本記事では○○について解説します」） |

## 5. 各ブロックの書き方

- **結論ファーストが鉄則**。ユーザーは答えを探しに検索し、早く欲しい。答えを提示して信頼関係を構築し、気づき・納得感へ読み進めさせる。
- **PREP 法**（物事の説明・論理的）: Point（結論）→ Reason（理由）→ Example（具体例）→ Point（結論）。比較なら Example を Comparison に。
- **SDS 法**（できごと・体験・感情的）: Summary（要点）→ Details（詳細）→ Summary（要点）。抽象 → 具体 → 抽象。
- 使い分け: 物事を説明するなら PREP、事実・体験を伝えるなら SDS。

## 6. タイトルとクリック率

- クリック率に影響する要素: ① 記事タイトル ② メタディスクリプション ③ 強調スニペット。
- タイトル: 原則 32 文字以内、最大 40 文字まで。無駄を省いて情報量を多くする。
- メタディスクリプション: 必須ではないが推奨。目安 140 文字。
- 強調スニペット: 構造化データでマークアップ可能。1 位の CTR 目安は 20% 程度。
- 魅力的なタイトルの 4 条件: ① 施策キーワードを必ず含める ② 読者の興味に言及する ③ 無駄を省いて情報量を増やす ④ キャッチーで魅力的に。
  - ✕ Webライター初心者でもわかる記事の作成方法を教えます
  - ○ Webライター初心者必見「SEOの基本と記事の書き方」

## 7. 離脱しない記事 — 装飾と構成

- ① 結論ファースト＆内容の提示。結論を補足するように書く。3 項目以上並列できる内容は箇条書きに。
- ② 装飾・表の活用で理解や比較を助ける。重要部分を分けて分かりやすく。
- ③ 図解や画像でテンポと理解促進。文字だけで難しいときは図解、テンポを変えるときは画像。
- 読み飛ばしても意味が分かるか、読者の感情を捉えているか、主張に目を止める間があるか、単調さを払拭できているか。

## 8. 記事内の内部リンク

- Web サイトは 1 本の木。枝がカテゴリーや中心記事、葉がキーワード記事、内部リンクは栄養を循環させるバイパス。
- 種類: ブログカード（目立つがリズムを壊すことがある）/ アンカーテキスト（青字が原則。基本）/ 画像リンク（バナー。導線設計が必須）。記事内はこの 3 つが基本。
- 重要なのは関連性。関係のない話題のリンクは評価されない。
- リンク先の選び方（フェーズ・単語数・カテゴリ）は content-marketing。
