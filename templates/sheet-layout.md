# スプレッドシート列定義（正本）

> 「設計フォーマット」の項目をそのまま列にする（ユーザー決定 2026-09-16）。列を増やすときは末尾に追加し、既存列を動かさない。1 実行 = 1 行。セル内の複数値は改行区切り、順位付きは `1) タイトル | URL` の形。日時は ISO8601（JST）。
> シート名は固定: `SERPs` / `上位5記事` / `記事分析` / `構成案` / `キーワードマップ`。/SEO設定 sheet がヘッダ行を作る。
