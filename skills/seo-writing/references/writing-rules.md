# Web ライティングの基本ルール（既定）

> 出典: SEOライティング 基礎マニュアル p.15〜18。SEO 記事に限らず Web 文章全般の既定。サイト固有の統一語・トンマナは knowledge/rules/media-rules.md が差分として上書きする。
> 「機械判定」列は gate_rules.yaml に落とす可否（templates/gate_rules.yaml に既定を収録）。

## 0. 前提 — 読者の 3 つの NOT [p.15]

読者は「読まない」「信じない」「行動しない」。疑心暗鬼で現状維持の人と仮定して配慮する。
- 読まない: 読み流す、見ない、気に留めない
- 信じない: 疑っている、方法はいくらでもある
- 行動しない: 今じゃなくていい、楽をしたい

## 1. 表記 [p.16]

| ルール | 内容 | 例 | 機械判定 |
|---|---|---|---|
| 英数字は半角が原則 | サイト上で数字を用いる場合は半角。記号は全角統一 | ２０１３年～２０１５年 ⇒ 2013年～2015年 / 8+3>3+2 ⇒ 8＋3＞3＋2 | 可（全角英数字の検出） |
| 表記ゆれは厳禁 | 同じ意味の単語は統一。サイトの対象者に合わせて決定 | web / Web / WEB / ウェブ ⇒ Web、様々 / さまざま ⇒ 様々 | 可（統一語辞書 = media-rules の差分） |
| トンマナの統一 | サイト上のイメージの統一（初心者向けか専門者向けか）。「です・ます調」「だ・だろう調」の統一、生物学的観点なら生物名はカタカナ統一など | | 一部可（文末の混在検出） |

## 2. 語の使い方 [p.17]

| ルール | 内容 | 例 | 機械判定 |
|---|---|---|---|
| 固有名詞は正式名称、略語は使用不可 | | ツイッター ⇒ Twitter、スマホ ⇒ スマートフォン | 可（略語辞書） |
| 話し言葉の使用は原則厳禁 | 「書き言葉」を用いる | ら抜き: 考えれる ⇒ 考えられる / い抜き: 分かってる ⇒ 分かっている | 一部可（ら抜き・い抜きパターン） |
| 二重表現に気をつける | 致命的ではないが冗長 | 必ず必要です ⇒ 必要です / まず最初に ⇒ 最初に or まず / 約80％程度 ⇒ 約80％ or 80％程度 | 可（辞書） |
| 同じ語尾の連続は原則 2 回まで | 単調な印象になる | 「私はWebライターです。丁寧な表現が得意です。コツは何度も見直しすることです。」⇒ 2 文目を「丁寧な表現を心掛けています。」 | 可（文末 3 連続の検出） |

## 3. 文の作り方 [p.18]

| ルール | 内容 | 例 | 機械判定 |
|---|---|---|---|
| 一文一義が基本原則 | 1 文に何個もの意味を含ませない。短く簡潔に | 「明日の天気は晴れですが、夕立の可能性があるため、お出かけ前には傘を持参しましょう。」⇒「明日の天気は晴れです。しかし、夕立の可能性があります。お出かけ前には傘を持参しましょう。」 | 一部可（文長・読点数の上限） |
| コピペ禁止、引用ルールを守る | コピペは信頼を低下させる。引用は blockquote タグで差別化し引用元を記載。著作権を守る。引用は改変禁止、参考は知恵を借りて自分で作る、参照は事実を示す | | 一部可（blockquote に出典があるか） |
| ネガティブな表現に注意する | 個人・商品・サービスの価値を落としたり、個人的な価値観による否定は避ける | ○○は使い物にならない / 費用がかかってしまう / 芸能人 A さんは○○である | 辞書で一部 |
| 冗長な表現を避ける | 周りくどい言い回しは不要。簡潔にストレートに | ○○することができます ⇒ ○○が可能です / ○○ということがいえます ⇒ ○○といえます | 可（辞書） |

## 4. 差分の取り方（media-rules と分担）

- この表が**既定**。サイトがこれと違う運用（例: 「だ・である調」、英字略語を許可、独自の統一語）をしているときだけ、その違いを `knowledge/rules/media-rules.md` に「既定 → 当サイト」の形で書く。
- 既定と同じ項目は media-rules に書かない（重複は乖離のもと）。
