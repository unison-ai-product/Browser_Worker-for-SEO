# 前提概念

> 出典: SEOライティング 基礎マニュアル p.4〜10。通常は読まない。判断に迷ったときの根拠。

## 1. ユーザーの検索行動 [p.4]

疑問 → 検索 → 解決 → 行動。ユーザーの検索行動を理解して回答を示すことがユーザーファーストの記事。検索した理由が検索意図で、最も重要な概念。

## 2. 検索インテントの 4 分類 [p.5]

| 分類 | 意味 | 例 |
|---|---|---|
| KNOW クエリ | ○○を知りたい | ブログとは |
| GO クエリ | ○○へ行きたい | 太郎ブログ |
| DO クエリ | ○○をしたい | ブログ 始め方 |
| BUY クエリ | ○○を買いたい | WordPress テーマ おすすめ |

## 3. 潜在ニーズ [p.6]

顕在意識は氷山の一角。顕在ニーズ（表面的）より潜在ニーズ（ユーザー自身も気付いていない本当のニーズ）の方が成約に近い。最終的にどうなりたいのかを深掘りしてピンポイントのアドバイスを。ざっくりしたニーズの記事には網羅性が求められる。

## 4. E-E-A-T [p.7]

Experience（経験: 自身の体験が盛り込まれオリジナリティがあるか）/ Expertise（専門性: ジャンルに特化した内容か）/ Authoritativeness（権威性: 誰が運用し周囲からどう評価されているか）/ Trust（信頼性: 読者にとって信頼に足る内容か）。これらが担保されたサイトが上質なコンテンツ。

## 5. SEO ライティングの 10 工程 [p.9〜10]

| 段階 | 工程 | 本プラグインの対応 |
|---|---|---|
| 事前調査 | ① キーワード選定 / ② 検索上位の把握 / ③ 検索意図の深掘 | キーワードマップ / ① SERPs解析・② 記事分析 / seo-analysis §1-5 |
| 記事戦略 | ④ 結論・主張の決定 / ⑤ 記事構成案の作成 | seo-outline §1 / ③ 構成案 |
| 記事制作 | ⑥ 原稿執筆 / ⑦ 画像挿入・装飾 | unit-drafter / diagram-maker・fix-integrator |
| チェック | ⑧ 推敲 / ⑨ 校正・校閲 / ⑩ 校了 | checklist.md |

事前調査で確認すること: 施策キーワードの難易度、必要な網羅性、月間検索ボリューム、サイト内でのキーワードのポジション、関連キーワードの拡張性（共起語）、ビッグ / ミドル / ロングテールのどれか、なぜ調べようと思ったか・緊急性、調べ終わった先の行動や疑問。ツールはラッコキーワード、キーワードプランナー、マインドマップ。
